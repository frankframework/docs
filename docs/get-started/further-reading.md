Now that you have Frank!Framework running, explore the documentation to build, deploy, and operate your integrations.

## Next Steps

- [Configuration](/docs/manual/category/configuration) — Learn how to write adapters, use pipes and senders, define properties, connect to databases, and handle large messages.
- [Deployment](/docs/manual/deployment) — Set up Docker images, configure DTAP stages, manage credentials, connect JMS queues, and customize logging.
- [Testing](/docs/manual/testing) — Write Larva unit tests and use Ladybug for debug capture and regression testing.
- [Operations](/docs/manual/operations) — Monitor adapter status, manage error stores, configure scheduling, and set up alerts.
- [Troubleshooting](/docs/manual/troubleshooting) — Solutions for common startup errors, configuration issues, and runtime problems.
